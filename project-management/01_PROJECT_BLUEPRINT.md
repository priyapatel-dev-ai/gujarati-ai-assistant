Status: Planning

- Dashboard

- AI Rewrite
- Documents
- Profile
- Admin Panel
- Subscription

- Frontend: React
- Backend: Django REST Framework
- Database: PostgreSQL
- Authentication: JWT
- CI/CD: GitHub Actions
- Containerization: Docker
