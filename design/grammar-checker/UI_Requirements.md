# Grammar Checker UI Requirements

## Purpose

The Grammar Checker is the primary writing workspace of the
Gujarati AI Writing Assistant.

It allows users to write or paste Gujarati text and receive
grammar, spelling and AI-powered suggestions.

## Layout

The screen contains three major areas:

1. Left Sidebar
2. Gujarati Text Editor
3. Suggestions Panel

## Left Sidebar

Navigation options:

- Dashboard
- Grammar Checker
- Spell Checker
- AI Rewrite
- Dictionary
- Documents
- Settings

## Text Editor

The editor allows users to:

- Type Gujarati text
- Paste Gujarati text
- Edit existing text
- View highlighted issues
- See word count
- See character count

## Suggestions Panel

Suggestions are grouped into:

- Grammar
- Spelling
- Sentence Improvement
- AI Suggestions

Each suggestion should provide:

- Original text
- Suggested correction
- Explanation
- Accept action
- Reject action
- Ignore action

## Bottom Actions

Primary actions:

- Check Grammar
- AI Rewrite
- Save
- Download

## Future Support

The UI should be designed so that future features can be added
without redesigning the complete screen.

Potential future features:

- Voice Input
- OCR
- PDF Import
- Translation
